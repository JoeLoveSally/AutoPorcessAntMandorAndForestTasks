## 设备与时延

测试设备：V2227A，1440×3200，ADB 序列号由本地 `config/config.toml` 配置。

| ADB 操作 | P50 | P95 | 结论 |
| --- | ---: | ---: | --- |
| 前台 Activity | 146 ms | 148 ms | 适合安全前置检查 |
| PNG 截图 | 2245 ms | 2437 ms | 适合普通页面，不适合能量雨 |
| UI 树 | 2555 ms | 2666 ms | 与截图组成普通页面完整观测 |

因此普通任务使用“截图 + UI 树 + 页面后置条件”，能量雨使用 Android `screenrecord` 原始 H.264 流与持续 ADB Shell 触控。滑动广告在首次确认页面后采用三次一组的已验证滑动，组间重新观测，避免每秒动作被完整观测的 2 秒以上延迟打断。

实时通道读取 5 帧用时 4.607 秒、读取 30 帧用时 4.799 秒；首帧包含 Android 编码器和 FFmpeg 解码器启动时间，后续帧以实时速率连续到达。scrcpy v4.1 官方包下载和校验通过，但其未封口 MKV 录制文件在本机组合下不能稳定被 FFmpeg 实时消费，所以仅保留为诊断依赖，不作为能量雨主通道。
